\begin{abstract}
We present BudgetBench, a standardized benchmark for evaluating memory strategies
for local LLMs under fixed active-context-budget constraints. The benchmark compares
pluggable memory strategies across 2K, 4K, 8K, 16K, and 32K active-context tiers
on deterministic task suites. This scaffold will be completed after the full study
results are collected.
\end{abstract}

\section{BudgetBench Framework}

\subsection{Task Suite}

BudgetBench combines software repair and long-context question answering. The current
Phase 4 sweep focuses on SWE-bench Verified and LongBench v2. The tau2-bench integration
is wired and remains a follow-up full-sweep candidate.

\subsection{Memory Strategy Interface}

Each memory strategy implements a common interface that maps input messages and an active
budget to budget-constrained messages for the LLM call. Baselines include truncation,
summary-buffer, RAG, Mem0, Letta/MemGPT, and LLMLingua-2.

\subsection{Budget Enforcement Protocol}

Every LLM call is wrapped by the active-budget protocol. If a strategy emits context
above the active tier, the harness records the violation and fails the combination
gracefully after bounded retry behavior.
