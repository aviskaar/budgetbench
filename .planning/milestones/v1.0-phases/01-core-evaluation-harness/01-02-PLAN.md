    Function `enforce_budget(messages, tokenizer_fn, max_tokens)`:

<task type="auto" tdd="true">
  <name>Task 2: Implement Evaluation Harness with Metrics Integration</name>
  <files>src/budgetbench/evaluation/harness.py, tests/test_harness.py</files>
  <action>
    Implement the evaluation harness in `src/budgetbench/evaluation/harness.py` (D-01, D-02, HARN-04).

    Function `run_evaluation_task(messages, strategy, llm_client, tokenizer_fn, max_tokens, logger, max_retries=3)`:
    1. Retry loop (up to `max_retries`):
       - Call `strategy(messages, max_tokens)`.
       - Call `enforce_budget(...)`.
       - If success: Call `llm_client(...)`, calculate metrics, and break.
       - If `BudgetExceededError`: Log violation (if needed) and retry.
    2. If all retries fail, raise error or log final failure.
    3. Call `logger.log_metrics(...)` with collected data (quality, used budget, peak, violations, tokens).
    
    Update `tests/test_harness.py` to verify the full flow: strategy call -> budget check -> LLM call -> metrics log.
  </action>

    <automated>PYTHONPATH=src pytest tests/test_harness.py -v</automated>
  </verify>

    - Harness successfully writes final metrics to the provided `MetricsLogger`.
    - Harness respects `max_retries`.
  </acceptance_criteria>
