  <name>Task 1: Implement τ²-bench Wrapper</name>
  <files>src/budgetbench/tasks/tau.py</files>
  <action>
    Create a wrapper for τ²-bench (retail and airline domains).
    - Use `tau2.envs.get_env` to initialize the simulator.
    - Implement a multi-turn agent loop:
      1. Get observation from `env.reset()` or `env.step()`.
      2. Construct message history including tool definitions.
      3. Call `run_evaluation_task` (harness) to get the next action.
      4. Parse tool calls from LLM response and call `env.step()`.
    - Extract success/failure from `info['success']` at the end of the episode.
    - Ensure tool definitions and system instructions are counted in the token budget.
  </action>

  </verify>
